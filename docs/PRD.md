---

## 1. 项目背景

### 1.1 业务痛点

工程主管日常管理 20-30 个项目、跟踪 50-90 个问题，现有管理方式存在以下问题：

- **信息分散**：使用多个 Excel 文件管理，查询不便，容易遗漏
- **缺乏预警**：靠记忆排优先级，风险容易被忽略
- **效率低下**：周报手工整理，重复劳动多
- **追踪困难**：问题状态流转不清晰，责任人不明确

### 1.2 项目目标

建立一套符合工程主管工作习惯的管理系统，实现：
- 项目信息集中管理
- 问题/风险自动预警
- 周报自动生成与发送
- 任务完成率可视化统计

## 2. 功能需求

### 2.1 项目管理模块

#### 功能描述

#### 功能列表

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 项目列表 | 展示所有项目，支持筛选（状态、阶段、PM） | P0 |
| 项目详情 | 查看项目完整信息，包含里程碑、问题、风险、人员 | P0 |
| 新增项目 | 创建新项目，填写基本信息 | P0 |
| 编辑项目 | 修改项目信息，更新进度、阶段等 | P0 |
| 删除项目 | 逻辑删除项目（保留数据） | P1 |

| 发票管理 | 记录项目开票信息，支持多期开票 | P1 |
| 进度跟踪 | 可视化展示进度百分比 | P0 |

| 字段 | 类型 | 说明 |
|------|------|------|
| 项目名称 | 文本 | 必填，唯一 |
| 客户 | 文本 | 项目所属客户 |

| 状态 | 文本 | 进行中/已完成/暂停 |

### 2.6 周报生成模块

#### 功能描述
自动生成周报内容，支持邮件发送。

#### 功能列表

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 周报预览 | 预览本周周报内容 | P0 |
| 周报生成 | 自动汇总本周项目/问题/风险/任务 | P0 |
| 邮件发送 | 发送周报到指定邮箱 | P0 |
| 邮件配置 | 配置SMTP服务器和收件人 | P0 |

#### 周报内容结构

1. **概览统计**：进行中项目数、活跃问题数、高风险数、任务完成率
2. **项目进度表**：各项目进度、成本使用率、工时使用率
3. **问题列表**：本周新增/待处理问题
4. **风险列表**：活跃风险及应对措施
5. **任务完成情况**：本周任务完成率统计
6. **重要事项**：各项目本周重要事项
