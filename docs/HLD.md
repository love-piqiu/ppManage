# 概要设计文档

## 1. 文档概述

本文档描述 ppManage 系统的概要设计，包含模块划分、接口设计、数据流程等内容。

---

## 2. 系统模块划分

### 2.1 模块总览

| 模块编号 | 模块名称 | 功能描述 |
|----------|----------|----------|
| M01 | 项目管理 | 项目信息CRUD、里程碑、发票管理 |
| M02 | 问题跟踪 | 问题CRUD、状态流转、预警 |
| M03 | 风险管理 | 风险CRUD、等级管理、应对措施 |
| M04 | 人员管理 | 人员CRUD、项目参与关联 |
| M05 | 任务管理 | 任务定义、完成率统计 |
| M06 | 周报生成 | 周报汇总、邮件发送 |
| M07 | 系统管理 | 用户、角色、菜单、日志（继承RuoYi） |

### 2.2 模块依赖关系

```
┌──────────┐
│ 系统管理 │ (基础模块，提供用户/权限)

     │             ▼             ▼             │
```

## 3. 核心模块设计

### 3.1 项目管理模块（M01）

#### 功能清单

| 功能ID | 功能名称 | 输入 | 输出 | 处理逻辑 |
|--------|----------|------|------|----------|
| F01-01 | 项目列表查询 | 筛选条件 | 项目列表 | 查询符合条件的项目 |
| F01-02 | 项目详情查询 | 项目ID | 项目详情 | 查询项目及关联数据 |
| F01-03 | 新增项目 | 项目信息 | 操作结果 | 校验并保存项目 |
| F01-04 | 编辑项目 | 项目信息 | 操作结果 | 校验并更新项目 |
| F01-05 | 删除项目 | 项目ID | 操作结果 | 逻辑删除项目 |
| F01-06 | 里程碑管理 | 里程碑信息 | 操作结果 | 保存项目里程碑 |
| F01-07 | 发票管理 | 发票信息 | 操作结果 | 保存开票记录 |

#### 主要接口

| 接口名称 | 请求方式 | URL | 说明 |
|----------|----------|-----|------|
| 项目列表 | GET | /system/project/list | 查询项目列表 |
| 项目详情 | GET | /system/project/{id} | 查询项目详情 |
| 新增项目 | POST | /system/project | 新增项目 |
| 编辑项目 | PUT | /system/project | 编辑项目 |
| 删除项目 | DELETE | /system/project/{id} | 删除项目 |

|--------|----------|------|------|----------|

| 类型 | 说明 | 截止规则 |
|------|------|----------|
| 每日 | 每天执行 | 指定时间点（如18:00） |
| 每周 | 每周执行 | 指定星期（如周五） |
| 每月 | 每月执行 | 指定日期（如每月5号） |
| 一次性 | 单次执行 | 指定日期 |

#### 功能清单

| 功能ID | 功能名称 | 输入 | 输出 | 处理逻辑 |
|--------|----------|------|------|----------|
| F06-01 | 周报预览 | 时间范围 | 周报内容 | 查询并组装周报数据 |

#### 周报数据来源

| 章节 | 数据来源 |
|------|----------|
| 概览统计 | 项目计数、问题计数、风险计数、任务统计 |
| 项目进度 | sys_project 表 |
| 问题列表 | sys_issue 表（本周新增+待处理） |
| 风险列表 | sys_risk 表（活跃状态） |
| 任务完成 | sys_task_instance 表 |
| 重要事项 | sys_project_milestone 表 |

## 4. 数据库概要设计

### 4.1 核心数据表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| sys_project | 项目表 | id, name, customer, pm_id, progress, stage, status |
| sys_project_milestone | 里程碑表 | id, project_id, description, record_date |
| sys_project_invoice | 发票表 | id, project_id, amount, invoice_date |
| sys_issue | 问题表 | id, project_id, description, severity, status |
| sys_risk | 风险表 | id, project_id, description, level, status |
| sys_person | 人员表 | id, name, position, level, status |
| sys_person_project | 人员项目关联 | id, person_id, project_id, role |
| sys_task | 任务定义表 | id, name, type, cycle, status |
| sys_task_instance | 任务实例表 | id, task_id, person_id, period, completed |
| sys_email_config | 邮件配置表 | id, host, port, username, recipient_email |

### 4.2 表关系图

```
sys_person ────┐
               │ N:M (sys_person_project)
               ▼
sys_project ◄────────────────────────────────┐
    │                                         │
    │ 1:N                                     │ 1:N
    ├──────────────┬──────────────┬───────────┤
    ▼              ▼              ▼           ▼
sys_milestone  sys_invoice    sys_issue   sys_risk

sys_task ────1:N───► sys_task_instance ────N:1───► sys_person
```

## 6. 性能设计要点

### 6.1 数据库优化

- 项目列表查询添加复合索引
- 大表查询使用分页
- 统计查询使用缓存

### 6.2 前端优化

- 列表页使用懒加载
- 表单使用防抖提交
- 大数据使用虚拟滚动

---

## 7. 安全设计要点

### 7.1 认证与授权

- 继承 RuoYi 的 Spring Security 认证
- JWT Token 机制
- 基于角色的权限控制

### 7.2 数据安全

- 敏感字段加密存储
- SQL注入防护（MyBatis参数化）
- XSS防护（前端过滤）
