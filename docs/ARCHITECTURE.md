# 架构设计文档

## 1. 系统概述

ppManage 采用经典的三层架构设计，基于 RuoYi-Vue 框架构建，实现前后端分离。

---

## 3. 技术选型

### 3.1 前端技术

| 技术 | 版本 | 用途 |
|------|------|------|
| Vue.js | 2.x | 前端框架 |
| Element UI | 2.x | UI组件库 |
| Axios | - | HTTP请求 |
| Vue Router | - | 路由管理 |

### 3.2 后端技术

| 技术 | 版本 | 用途 |
|------|------|------|
| Spring Boot | 2.x | 后端框架 |
| MyBatis | - | ORM框架 |
| MySQL | 5.7+ | 数据库 |
| Redis | 6.0+ | 缓存/会话 |
| Quartz | - | 定时任务 |

### 3.3 基础框架

基于 **RuoYi-Vue** 框架，继承以下能力：
- 用户权限管理
- 角色菜单管理
- 操作日志记录
- 定时任务调度
- 系统监控

## 5. 数据流设计

### 5.1 标准CRUD流程

```
用户操作 → Vue组件 → Axios请求 → Controller → Service → Mapper → MySQL
                ↓
           Element UI渲染响应
```

### 5.2 周报生成流程

```
定时任务触发 → ReportService.generateWeeklyReport()
                    ↓
              查询本周数据（项目、问题、风险、任务）
                    ↓
              组装周报内容结构
                    ↓
              EmailService.send() → SMTP服务器
                    ↓
              发送至收件人邮箱
```

## 6. 安全架构

### 6.1 认证流程

```
用户登录请求
    ↓
Spring Security 验证
    ↓
生成JWT Token
    ↓
Token存入Redis
    ↓
返回Token给前端
    ↓
前端请求携带Token
    ↓
SecurityFilter验证Token
    ↓
允许访问资源
```

### 6.2 权限控制

- **菜单权限**：基于角色控制菜单可见性
- **按钮权限**：基于权限标识控制按钮操作
- **数据权限**：基于用户角色过滤数据范围

## 8. 扩展性设计

### 8.1 模块扩展

新增业务模块只需：
1. 创建 domain/mapper/service/controller
2. 前端创建对应 views/api
3. 配置路由和菜单

### 8.2 接口扩展

支持 RESTful API 扩展，便于：
- 移动端接入
- 第三方系统集成
- 数据导入导出

---

## 9. 关键设计决策

| 决策 | 理由 |
|------|------|
| 选择RuoYi-Vue | 成熟稳定、权限完善、快速开发 |
| 前后端分离 | 易于维护、便于扩展 |
| MySQL数据库 | 关系型数据适合业务场景 |
| Redis缓存 | 提升性能、支持会话管理 |
