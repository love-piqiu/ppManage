# 用户手册

## ppManage - 项目及人员管理系统

---

## 1. 系统简介

ppManage 是一个面向工程主管的项目管理工具，帮助您高效管理项目、跟踪问题、识别风险、协调人员、安排任务，并自动生成周报。

### 1.1 系统功能

| 功能模块 | 说明 |
|----------|------|
| 项目管理 | 管理项目信息、进度、成本、工时、里程碑 |
| 问题跟踪 | 跟踪项目问题，管理状态流转 |
| 风险管理 | 识别和管理项目风险 |
| 人员管理 | 管理团队成员信息和项目参与情况 |
| 任务管理 | 管理周期性任务，统计完成率 |
| 周报生成 | 自动生成周报并发送邮件 |

## 4. 项目管理

### 4.1 查看项目列表

**路径**：项目管理 → 项目列表

项目列表页面展示所有项目，支持以下操作：

| 操作 | 说明 |
|------|------|
| 搜索 | 按项目名称/客户名称搜索 |
| 状态筛选 | 筛选进行中/已完成/暂停项目 |
| 阶段筛选 | 筛选特定阶段的项目 |
| 查看详情 | 点击项目名称查看详情 |
| 新增项目 | 点击「新增」按钮 |
| 编辑项目 | 点击「编辑」按钮 |
| 删除项目 | 点击「删除」按钮 |

### 4.2 项目详情页

点击项目名称进入详情页，包含以下信息区：

| 区域 | 内容 |
|------|------|
| 基本信息 | 项目名称、客户、PM、销售、成本、工时、进度 |
| 阶段时间 | 各阶段（需求/UAT/上线/验收）的计划和实际时间 |
| 里程碑 | 项目重要事项记录 |
| 问题列表 | 该项目关联的问题 |
| 风险列表 | 该项目关联的风险 |
| 参与人员 | 项目团队成员 |
| 发票记录 | 开票信息（如有） |

### 4.3 新增项目

1. 在项目列表页点击「新增」
2. 填写基本信息：
   - **项目名称**（必填）：唯一标识
   - **客户**：项目所属客户
   - **项目经理**：从人员列表选择
   - **销售**：从人员列表选择
   - **成本**：项目总成本（万元）
   - **工时**：总工时预算（人天）
   - **合同金额**：合同金额（万元）
   - **是否下辖**：是否为本部门项目
   - **项目类型**：外包/自营
   - **开始日期**：项目启动时间
   - **计划结束日期**：预期完成时间
3. 点击「确定」保存

### 4.4 编辑项目

1. 在项目列表找到目标项目
2. 点击「编辑」按钮
3. 修改需要更新的信息
4. 点击「确定」保存

### 4.5 记录里程碑

在项目详情页的「重要事项」区域：

1. 点击「新增」按钮
2. 填写事项描述和日期
3. 点击「确定」保存

## 5. 问题跟踪

### 5.1 查看问题列表

**路径**：项目管理 → 问题管理

列表展示所有问题，顶部显示统计：
- 待处理数
- 进行中数
- 已解决数
- 已关闭数

支持筛选：
- 按项目筛选
- 按状态筛选
- 按严重程度筛选

### 5.2 新增问题

1. 点击「新增」按钮
2. 填写问题信息：
   - **关联项目**（必填）：选择项目
   - **问题描述**（必填）：详细描述问题
   - **问题类型**：技术/业务/管理
   - **严重程度**：高/中/低
   - **负责人**：选择责任人
   - **发现日期**：问题发现时间
   - **计划解决日期**：预期解决时间
3. 点击「确定」保存

### 5.3 状态流转

问题状态按以下流程流转：

```
待处理 → 进行中 → 已解决 → 已关闭
```

更新状态方法：
1. 进入问题详情页
2. 点击状态标签切换状态
3. 如选择「已解决」，填写解决方案和实际解决日期
4. 点击「确定」保存

### 5.4 高严重度问题预警

严重程度为「高」的问题会在列表中用红色标记，需优先处理。

## 6. 风险管理

### 6.1 查看风险列表

**路径**：项目管理 → 风险管理

列表展示所有风险，支持筛选：
- 按项目筛选
- 按风险等级筛选（高/中/低）
- 按状态筛选（潜在/已发生/已消除）

### 6.2 新增风险

1. 点击「新增」按钮
2. 填写风险信息：
   - **关联项目**（必填）：选择项目
   - **风险描述**（必填）：描述风险内容
   - **风险等级**：高/中/低
   - **应对措施**：预防或处理方案
   - **负责人**：选择责任人
3. 点击「确定」保存

### 6.3 风险状态

| 状态 | 说明 |
|------|------|
| 潜在 | 风险尚未发生，需预防 |
| 已发生 | 风险已出现，需处理 |
| 已消除 | 风险已解决 |

### 6.4 高等级风险预警

风险等级为「高」的风险会用红色标记，需重点关注。

## 7. 人员管理

### 7.1 查看人员列表

**路径**：项目管理 → 人员管理

列表展示所有团队成员信息：
- 姓名、职位、等级
- 年龄、工作年限、入司年限
- 在职状态

支持筛选：
- 按在职/离职状态筛选
- 按等级筛选

### 7.2 新增人员

1. 点击「新增」按钮
2. 填写人员信息：
   - **姓名**（必填）
   - **职位**
   - **等级**：B20/B30/B40等
   - **联系方式**
   - **邮箱**
   - **入职日期**
   - **学历**
   - **毕业院校**
3. 点击「确定」保存

### 7.3 人员详情

点击人员姓名可查看：
- 完整个人信息
- 参与的项目列表
- 本周任务完成情况

## 8. 任务管理

### 8.1 查看任务列表

**路径**：项目管理 → 任务管理

页面展示：
- 所有任务定义
- 本周完成率统计
- 人员完成情况矩阵

### 8.2 新增周期任务

1. 点击「新增」按钮
2. 填写任务信息：
   - **任务名称**（必填）
   - **任务类型**：选择「周期性」
   - **周期**：每日/每周/每月
   - **截止时间**：
     - 每日：设置截止时间点（如18:00）
     - 每周：设置截止星期（如周五）
     - 每月：设置截止日期（如每月5号）
   - **任务描述**
3. 点击「确定」保存

### 8.3 标记任务完成

在任务矩阵中：
1. 找到您的任务行
2. 点击当前周期的单元格
3. 选择「已完成」

### 8.4 完成率统计

系统自动计算：
- 本周整体完成率
- 每个人的完成率
- 是否按时完成

## 9. 周报生成

### 9.1 查看周报

**路径**：周报管理

页面展示本周周报预览，包含：

| 章节 | 内容 |
|------|------|
| 概览统计 | 项目数、问题数、风险数、完成率 |
| 项目进度表 | 各下辖项目的进度和使用率 |
| 问题列表 | 本周新增和待处理问题 |
| 风险列表 | 当前活跃风险 |
| 任务完成情况 | 本周任务完成统计 |
| 重要事项 | 本周各项目里程碑 |

### 9.2 发送周报

1. 确认周报内容无误
2. 点击「发送邮件」按钮
3. 系统发送邮件到配置的收件人

### 9.3 配置邮件

**路径**：周报管理 → 邮件配置

填写 SMTP 配置：
- **SMTP服务器**：如 smtp.qq.com
- **端口**：如 465
- **账号**：发件邮箱账号
- **授权码**：邮箱授权码（非密码）
- **收件人邮箱**：多个用逗号分隔
- **发送时间**：设置定时发送（如每周五）

## 10. 常见问题

### Q1: 忘记密码怎么办？

联系系统管理员重置密码。

### Q2: 项目名称重复怎么处理？

系统不允许项目名称重复，请使用不同的名称。

### Q3: 为什么周报没有发送？

检查：
1. 邮件配置是否正确
2. SMTP服务器是否可用
3. 授权码是否有效

### Q4: 任务完成率统计不准？

确认：
1. 任务是否正确生成实例
2. 所有人员是否都已标记完成状态

### Q5: 非下辖项目为什么会出现在周报？

周报只统计「下辖项目」（is_subordinate = "是"），请检查项目属性。
